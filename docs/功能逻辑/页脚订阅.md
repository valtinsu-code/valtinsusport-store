# 页脚订阅

页脚先使用现有 customer 表单的 action 和完整 FormData 向 Shopify 提交邮箱及 newsletter 标签，再调用现有 Klaviyo 订阅函数。Shopify 返回非成功 HTTP 状态时显示现有错误提示，不继续调用 Klaviyo。

验证步骤：使用测试邮箱提交，在浏览器网络面板核对 Shopify 请求字段和响应，再分别检查 Shopify 客户订阅状态及 Klaviyo 名单；开启双重确认时完成确认邮件操作。Shopify 可能返回验证页面，HTTP 成功本身不能证明订阅完成。
